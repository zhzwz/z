包住应用根。它透传 naive-ui 的 [ConfigProvider](https://www.naiveui.com/zh-CN/os-theme/components/config-provider) props，并额外做这些事：

- 最外层默认中文（`zhCN`、`dateZhCN`）。`locale` 传 `null` 则用 naive 自带的英文。
- 最外层没传 `theme` 时读 `<html data-z-theme>`（`light`、`dark`、`auto`；没写按 `auto`）。传了 `theme` 就用传入的值。切换用 `setZnTheme()`。
- 强调色只看 `<html data-z-accent>`（`blue`、`cyan`、`orange`）。没写时写成默认的 `blue`。`ZnAccentPanel`、`ZnAccentSwitch` 和 `setZAccent()` 都只改这个属性。色阶和 `setZAccent()` 从 `@zhzwz/z/accent` 引入。每套 11 阶，页面里用 `var(--z-theme-accent-500)`。亮色按钮取 `600`，暗色取 `400`。
- 最外层带上 `NLoadingBarProvider`、`NDialogProvider`、`NNotificationProvider`、`NMessageProvider`，里面可以直接用 `useMessage()` 等。嵌套的 `ZnConfigProvider` 不再重复套这几层。
- `defaults` 按组件名覆盖内置默认值。优先级从高到低：组件上显式传的 prop、内层 `defaults`、外层 `defaults`、内置默认值、naive 默认值。

内置默认值包括：输入类可清空，下拉可搜索，日期可清空并打开年月快选，开关不是圆角。`defaults` 里组件不接受的键会被忽略，不会透传给 naive。`class`、`style` 等未声明属性同样不接收。
