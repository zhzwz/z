用 `v-model` 绑定，不提供 `value`。`type` 只有 `text` 和 `password`，多行文本用 `ZnTextarea`。

空字符串会保留。用户点清空时写成 `null`。在 `ZnConfigProvider` 里，默认可清空。

其余 props 与 naive-ui 的 [Input](https://www.naiveui.com/zh-CN/os-theme/components/input) 一致。
